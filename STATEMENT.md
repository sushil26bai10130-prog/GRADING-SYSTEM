Student Grading System

1. Problem Statement

Manually calculating a student's total marks, percentage, average, grade, and pass/fail result can take time and may lead to calculation errors. This project provides a simple Python-based solution that automatically performs these calculations and stores the result.

2. Project Objective

The objective of this project is to create a simple student grading system that accepts student details and marks for five subjects, calculates the required results, assigns a grade, determines the result status, and saves the final record in a CSV file.

3. How the Project Works

1. The program takes the student's name and roll number.
2. It accepts marks for English, Hindi, Physics, Maths, and Chemistry.
3. It calculates the total marks out of 500.
4. It calculates the percentage and average marks.
5. It assigns a grade according to the percentage.
6. It determines whether the student has passed or failed.
7. It saves the student's result in a CSV file.

4. Modules Used

math: Used for calculating the percentage accurately using the floor function.

statistics: Used to calculate the average of the five subject marks.

csv: Used to save the student's result in a CSV file.

os: Used to display the location of the saved CSV file.

5. Main Features

- Student name and roll number input
- Five-subject marks input
- Automatic total marks calculation
- Percentage calculation
- Average calculation
- Automatic grade calculation
- Pass/Fail result
- Saving results in a CSV file

6. Input and Output

Input: Student name, roll number, and marks in five subjects.

Output: Total marks, percentage, average, grade, pass/fail result, and saved CSV record.

7. Conclusion

The Student Grading System is a simple Python project that automates basic student result calculations and record keeping. It demonstrates the use of user input, lists, arithmetic operations, conditional statements, Python modules, and CSV file handling.
